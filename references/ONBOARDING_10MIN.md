# 10 分钟准入说明（研究生 / 新同事版，2026-11-03）

> 这份文件回答三个问题：**我该给它什么**、**它会还我什么**、**我不能拿它说什么**。
> 读完还不能上手，说明这份文件写失败了——请提 issue。

## 0. 一句话定位

它不预测 ADMET，它判断**"你手上的多个 ADMET 预测结果，哪些能拿来做决定"**。
如果你只有一个源、只想看 logP——直接用 RDKit，不要用这个。

## 1. 你要给它的最小输入

一个 CSV，至少两列：

```csv
compound_id,input_smiles
C001,C[C@H](N)C(=O)O
C002,CC(=O)Oc1ccccc1C(=O)O
```

**关于立体化学（最容易卡住的一关）**：入口闸门要求"立体已声明"，
手性分子写成 `CC(N)C(=O)O` 会被判 `fail` 并挡在已发布流水线之外。
这不是刁难，是因为本包实测过 2/14 的结构错误都源于立体丢失。

- ✅ 正确：`C[C@H](N)C(=O)O`（L-丙氨酸）
- ⚠ 若你手上确实没有立体信息（供应商目录常见）：**不要**自己猜，
  先用 `python -m adt.cli normalize` 看清 `input_gate.csv` 里被标了什么，
  再决定"补立体"还是"明确声明该分子按外消旋体处理"。
- ❌ 不要做的事：把名字当 SMILES 传进去（名称→结构一律被拦，见红线 1）。

## 2. 三条命令（覆盖 80% 场景）

```bash
# 1) 标准化 + 输入闸门（看 input_gate.csv 有没有 fail）
python -m adt.cli normalize --input hits.csv --outdir out

# 2) 多源取数（需要网络/API；离线用快照重放 ADT_REPLAY=1）
python -m adt.cli web --compounds out/compounds.csv --outdir out

# 3) 裁决 + 报告（报告会自动过红线闸门，违规就不给你文件）
python -m adt.cli reliab --in out/measurements.csv --outdir out
python -m adt.cli report --reliability out/reliability.csv --outdir out
```

产出里最重要的是 `reliability.csv` 的 **verdict 三态**：
`PASS / FAIL / UNDETERMINED`。**UNDETERMINED 不是失败，是"证据不够，别硬判"**——
这正是它存在的理由。看 `action` 列它会告诉你下一步补什么。

## 3. 样本量的硬边界（不要试探）

| 你的分子数 n | 它能给你什么 | 它不能给你什么 |
|---|---|---|
| n < 10 | **只有定性结论**（框架会打横幅并拒绝报率/差/排序） | 任何百分比、任何排名、任何"优于" |
| 10 ≤ n < 30 | 点估计 + 95% CI | 不能说"稳健"，排序要显式加 `--force` 并标 OVERRIDE |
| n ≥ 30 | 可排序（还需满足簇占比、跨源极差等条件） | 仍不能说"证明/安全/无毒" |

**红线 2 会真的拦你**：n<10 时报告里的比率类表述会被拒绝落盘。

## 4. 三条禁令（违反会被代码拦，不是被劝）

1. **不许把 ΔG 换算成 Kd 或占有率**——对接打分没有这个物理基础。
2. **不许用预测值推断人体剂量或安全窗**——需要 PBPK/实测，本工具只给量级。
3. **不许写"证明/无毒/安全"**——最高只能写"一致指向 / 未见风险信号"。

## 5. 报告的可用性边界（评审/答辩必问）

- 它给的是**证据准入判断**，不是**活性预测**；不要拿它的 AUC 和 TDC 排行榜比。
- 端点结论是**端点依赖**的：hERG 上"门没判别力"不能外推到 DILI。
- 外源数字必须带来源标签：`temporal holdout（非预注册前瞻）`，不得写成"前瞻验证通过"。

## 6. 使用分级（默认 T1）

| 档 | 谁能用 | 产出能进哪 |
|---|---|---|
| **T1 探索**（默认） | 任何人 | 组会、内部讨论；产物标 `exploratory` |
| **T2 决策** | 有实测数据或明确代价模型的课题组 | 立项/采购决策 |
| **T3 发表** | 需 `--publish` + 快照重放 + 输入全部通过准入 | 论文/对外报告 |

`--publish` 不是装饰：它会强制红线 3（快照重放）与红线 1（结构准入），
任一不满足就 exit 4，**不给你文件**。

## 7. 遇到问题先看哪里

| 现象 | 先看 |
|---|---|
| 报告没生成，出现 `REDLINE_VIOLATIONS.md` | 打开它，里面逐条写了哪个红线、怎么改写 |
| 全是 UNDETERMINED | `reliability.csv` 的 `reason` 列：域外？单位异构？独立组不足？ |
| 某源全零/全越界 | `coverage_matrix.csv` 的 `no_prediction` 标记；该源在你的化学类上可能不可用 |
| 想知道某个数字从哪来 | `manifest_sha1` + `CLAIMS_REGISTRY.yaml`（每个数字都绑了产物路径） |
