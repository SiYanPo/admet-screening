# 定位与升维（R31 / 评审 B7）

> 评审原话（要点）："这个工作的贡献是**方法学**的（证据准入先于证据组合），但材料把它
> 写成了**工程工具**的自我介绍。应升维为『方法学主文 + 基准伴文』两篇，并对标
> OECD (Q)SAR 验证原则与 selective prediction 文献，而不是只在 ADMET 工具箱里比功能。"

## 1. 为什么必须升维（问题不在措辞，在读者）

当前材料的组织方式是"我能跑什么命令 + 我跑了什么"。这会让方法学审稿人问三个它答不了的问题：

1. **可证伪的命题是什么？** —— "准入层有用"不是命题，"在什么代价区间、对哪些端点、
   准入层显著优于无准入"才是命题。
2. **与已有形式的差别在哪？** —— 适用域（AD）、conformal、selective prediction 都已处理
   "什么时候不该信"，必须说清本框架多做了什么，而不是重新发明。
3. **失效边界在哪？** —— 方法学主文的价值一半在"什么时候不管用"。

## 2. 两篇的分工

### 主文（methodology）：证据准入作为独立决策层

- **命题**：多源证据组合的正确性前提是"每个证据体是否有资格进入组合"；该资格判定应
  独立于组合器、可审计、带归因，且其代价（弃权率）必须与收益（错误代价）在同一效用函数下衡量。
- **形式化**：给定源集合 S、端点 e、代价三元组 `c=(c_abstain, c_false_PASS, c_false_FAIL)`，
  决策流 A（含准入）与 B（无准入）的差异定义为 `Δu = u(A) − u(B)`；
  **主张必须写成条件命题**："当 `c_abstain ≤ 0.2·c_false_FAIL` 且 `c_false_PASS ≥ 5·c_false_FAIL` 时，
  Δu > 0 在 8/9 个 (端点×端点) 组合上显著为正"——这才可被反驳。
- **可证伪预测**（写进主文，供他人打靶）：
  1. 弃权成本升高时，准入层的净收益转负（**已实测成立**：abstain ≥0.5 → 5/9 显著更差）；
  2. 准入层对"域外但可判"的样本会过度弃权（**已实测成立**：hERG 上误杀率 0.826）；
  3. 独立方法组不足时，任何组合器的输出都不应被解读为共识（**已实测**：DILI 四源四种失效）。
- **消融**：4 策略 × 3 端点 × 20 种子的成本扫描，报"稳定区宽度"而非单点胜负。

### 伴文（benchmark）：准入层的可复现基准

- 数据：TDC 官方切分（hERG / DILI / BBB_Martins / Caco2），快照 + sha256 固定。
- 指标：cost-weighted utility（主）、coverage、risk@coverage、AUC（辅）、误放率/误杀率（准入层专属）。
- 基线：朴素多数投票、AD-guard、校准+conformal、完整准入；全部开源可重跑。
- 交付：`replication/` 挑战包（只给指标 + 容差 + 快照），外部第二实现者独立复现。

## 3. 对标（不是"首次提出"，而是"接在哪"）

| 传统 | 它处理什么 | 本框架的位置 |
|---|---|---|
| **OECD (Q)SAR 验证五原则**（defined endpoint / unambiguous algorithm / **defined applicability domain** / goodness-of-fit & robustness & predictivity / mechanistic interpretation，OECD 2007；AD 方法综述见 Netzeva 2005、Sahigara 2012） | 单模型能否被监管采信 | 把"defined AD"从**单模型的一次性声明**变成**逐源、逐端点的可审计判定**，并给出域外时的**弃权**而非"仍然给数" |
| **Reject option / selective prediction**（Chow 1970 的最优拒识；El-Yaniv & Wiener 2010 的 noise-free selective classification；Geifman & El-Yaniv 2017 的 risk–coverage 曲线） | 单模型"何时不该答" | 把弃权从**单模型的分数阈值**推广到**多源证据的准入**：弃权的原因是"源没资格"，不是"分数不够高" |
| **Conformal prediction**（分割 conformal、Mondrian 条件覆盖） | 给定覆盖率的集合预测 | conformal 只在"源已被准入"之后才有效——本框架处理它**默认成立的前提**；二者是串联关系 |
| **Dempster–Shafer / 证据组合** | 冲突证据的融合 | DS 需要"证据体可信"的先验；本框架的 `source_conflict` 是把"冲突"作为**弃权理由**而非融合对象 |

**必须同时写清的"不是"**（novelty claim 降级，防过度主张）：

- 不是"首个提出适用域"；AD 有二十年文献。
- 不是"首个做弃权"；reject option 始于 1970。
- 不是"全面优于 SOTA 模型"；本框架**主动与 TDC leaderboard 脱钩**——它评的是"证据该不该用"，
  不是"预测能到多少 AUC"。
- 贡献边界应写成：**把"源资格"显式化为独立决策层，并给出它的代价-收益边界与失效模式**。

## 4. 主文必须包含的负面结果（否则不构成方法学论文）

| 负面结果 | 实测数字 | 为什么必须写 |
|---|---|---|
| 准入层收益依赖代价区间 | ref 代价下 hERG Δu=−0.197、BBB −0.223（**更差**） | 不写就是把条件命题写成无条件承诺 |
| 准入层在 hERG 上**未证明**有判别力 | gate-as-classifier AUC **0.58**，95%CI **[0.46, 0.70]**，误杀率 **0.826** | 区间上界越过 0.65 → **不能**写"已证明无判别力"，只能写"未证明有"；说明"弃权"多数是过度保守，而非精准识别不可信样本 |
| 端点三级政策会清空可裁决结论 | run6 156 判定 → 按政策后 **0 PASS / 0 FAIL** | 说明"诚实"的代价是当下没有可交付裁决，这本身是结论 |
| 小样本下准入层不可用 | n=6 时 coverage 0.833→0 | 给出方法的最小可行样本量声明义务 |

## 4b. 主文**必须**包含的一条正面结果：Ames 双方法层（评审 R2 的原话：「唯一改了行为且数字变好」）

前三轮里所有数字几乎都在削弱这个框架。**唯一一个反方向的**，是 Ames 端点上的"统计模型 + 专家规则层"：

| 口径（ICH M7(R2)，n=1457，prevalence 0.597） | 只看统计模型 | 统计模型 + 专家规则层 | 变化 |
|---|---|---|---|
| 放行率（判 Class 5 方向） | 0.399 | **0.155** | 更保守 |
| **放行的真致突变物** | 156 | **40** | **−74.4%** |
| **放行错误率**（= 放行中真致突变占比） | **0.2685** [0.234, 0.306] | **0.177** [0.133, 0.232] | **−9.15 个百分点（95%CI −4.79 ~ −13.45，不含 0）** |
| FAIL 精确率 | — | 0.746 | 报警更值得信 |

**区间（P2.4 / 解 D3，2026-11-03 补算）**：原表只有点估计，审稿人必然追问"9.2pp 的 CI 是多少"。
现由 `run_ames_release_ci.py` 按四格重建做**配对 bootstrap**（10,000 次重抽，固定种子）：
差值 **0.0915，95%CI [0.0479, 0.1345]**，不含 0 → 可以写"差异 9.2pp（95%CI 4.8–13.5）"。
交叉核对（Newcombe 独立近似，忽略配对）为 [0.0266, 0.1495]，方向一致。
**假设须一并声明**：两法放行集嵌套（规则层只能降级不能升级），四格由聚合计数重建，
非逐分子记录——见产物 `assumption` 字段。产物：`out_ext/tdc/ames_release_ci.json`。

产物：`out_ext/tdc/ames_alerts.json`（`two_method_ich_m7.release_error_rate = 0.177`；`stat_only_counterfactual.release_error_rate = 0.2685`，文档四舍五入写 0.269，已在 `CLAIMS_REGISTRY.yaml::ames_release_error` 的 `doc_rounding` 注明）。

**为什么这条值得当"产品故事"讲**（而不仅是又一条结果）：

1. **它是唯一"行为改变"的证据**。前三轮的成果都是"我们知道自己不知道"——那是诚实，不是能力。这一条是"我们因此少放过了 116 个致突变物"，是能力。
2. **它的机制是可迁移的**：把"统计模型给概率"与"专家规则给不可忽略的结构警报"分成两层，**任一层报警即升级**，
   而不是把两者塞进一个分数。这正是本 skill 的核心命题（证据准入先于证据组合）在**单个端点内部**的缩影——
   规则不是"另一个特征"，它是**有否决权的证据体**。
3. **它的代价被同时报出**：放行率从 0.399 掉到 0.155，意味着 244 个真阴性被误挡。**只报 −9.2 点不报 −24.4 点放行率，
   就是本文档 §4 所批评的那种选择性呈现**。所以这条必须与"过度保守"并列写。

**边界（防止把局部胜利读成普遍胜利）**：这条只在 Ames 成立，且依赖 ICH M7 的"两方法一致才放行"口径；
hERG / DILI / BBB 三端点上同一思路**没有**带来增益（gate 三端点 AUC 0.580 **[0.456,0.701]** / 0.668 **[0.543,0.793]** / 0.514 **[0.440,0.595]**，点估计全部低于 0.65；其中只有 BBB（n=406）的区间上界也低于 0.65，另两个端点属"不可判"）。
正确的表述是：**当存在一个高特异性、高可解释性的结构警报体系时，双方法层能实质降低放行风险；
当不存在时，本框架只能提供诚实，不能提供增益。**

## 5. 写作顺序（评审建议的实际执行）

1. 先写主文的"命题 + 可证伪预测 + 失效边界"三节（不依赖任何新数据）；
2. 再用伴文的数据填"消融"与"稳定区"；
3. 最后写 Introduction 的定位段（此时才知道自己到底接在哪条线上）。

## 6. 策略裁决（2026-11-18，用户授权下的专业判断，不再悬置）

此前 §4/§5 留有 5 项"待用户定夺"的学术分歧；用户已授权按专业判断直接裁决并执行。
**完整依据见 `references/STRATEGIC_DECISIONS_2026-11-18.md`**，此处仅列结论：

| # | 分歧 | 裁决 |
|---|---|---|
| 1 | 负结果是否包装为正面贡献 | **是**：唯一对外 framing = "准入层失效边界的检测框架"，负结果是一等输出而非歉疚项；主图必须是代价区间×端点×Δu 边界图 |
| 2 | 是否为 RR 再投入 | **是**：致命伤是 estimand 未绑定而非结果负；RR 把负结果升级为确证，边际成本低、期望收益高 |
| 3 | 旗舰刊 vs 专门刊 | **双轨**：主线 Stage 1 RR 投 soundness 刊（PLOS ONE / Nat Hum Behav / Elsevier RR 表）；负结果专集 backup；**本轮不投 Nature Methods** |
| 4 | estimand 定位 | **时序两阶段**：当前回溯材料对推断性结论是致命缺陷（必须撤销推断资格）；Stage 1 冻结后转为确证前提。当前可标"探索性"但不得复活撤回结论 |
