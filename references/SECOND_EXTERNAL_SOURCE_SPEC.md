# 第二外源集执行规范（P2.5，2026-11-03）

> **为什么必须有第二外源集**：当前"外源"结论（E1：AUC 随最近邻 Tanimoto 单调下降）
> 是**单源单端点**证据——ChEMBL_37 的 hERG IC50。红线的精神是"端点依赖类结论必须
> 三端点并列"，那么"跨数据集结论"更必须至少双源双端点，否则同一把刀会砍到自己。
> 外部评审 R-B 的补充要求：**换源的同时必须换端点**，否则"跨源"只在数据源维度成立、
> 端点维度仍是单的。

## 1. 目标命题（可证伪）

**H1（跨源稳健性）**：E1 的单调关系（最近邻 Tanimoto 越低 → AUC 越低）在
**第二个独立数据源**上复现，方向一致，且斜率符号相同。

**H2（跨端点稳健性）**：该单调关系在**第二个端点**上复现，且幅度差异可用该端点的
测定噪声/基线率解释（不要求数值相同）。

**判读**（预先写死，不得事后调整）：
- 两条都成立 → E1 可升级为"跨源跨端点稳健"，允许在主文写"一般性观察"；
- 仅 H1 成立 → 只能写"在某端点上的跨源一致性"；
- 都不成立 → 必须写成边界条件（这同样是有效结论，见 `POSITIONING.md` §4）。

## 2. 源与端点的选择规则（按优先级，先到先得）

| 优先级 | 源 | 端点 | 为什么 | 风险 |
|---|---|---|---|---|
| 1 | **OpenADMET ExpansionRx**（已随包，CC-BY-4.0） | **CYP3A4 抑制 / 溶解度** | 数据已在本地、许可干净、非 hERG | 样本量偏小（n≈2.7 万条但端点数少） |
| 2 | **NPASS**（天然产物，CC-BY-NC） | 任意活性终点 | 与本包"大极性天然产物"案例直接相关 | NC 许可：商用档必须走 `--profile commercial` 自动禁用 |
| 3 | **PubChem BioAssay**（public domain） | hERG 之外的离子通道 | 完全开放、可复现 | 需自建清洗管线（活性类型混杂） |
| 4 | ChEMBL 另一端点（如 DILI 相关 assay） | DILI | 同一 API，成本最低 | **同源**，只能做 H2，不能做 H1 |

**硬约束**：
- 不得选择"已经在训练/调参中用过"的数据（否则是新瓶装旧酒）；
- 必须有 `document_year` 或等价时间字段，以便区分 temporal holdout 与时间混合；
- 必须能算出最近邻 Tanimoto（即需要 SMILES），否则 E1 无法在该源上定义。

## 3. 执行步骤（每步都有产物）

1. **登记源**（F1 门）：`references/02_source_registry.yaml` 增加条目，
   `independence_group` 必须与现有源不同（hERG 专家模型不能算独立源）。
   验收：`python -m adt.cli indep-power` 与 `source-rho` 不报冲突。
2. **取数并落快照**：走 `adt.snapshot.fetch`（`ADT_SNAPSHOT=1`），
   落 sha256；**不得**直接把 DataFrame 塞进 `out_ext/`。
   验收：`release-check` 的 G2 依然 PASS。
3. **计算 E1 三件套**：最近邻 Tanimoto 分布、分箱 AUC、单调性检验（Spearman ρ + 置换检验）。
   产物：`out_ext/external2/<source>_<endpoint>_e1.json`。
4. **登记主张**：进 `CLAIMS_REGISTRY.yaml`（artifact + 字面量），否则 G10 红。
5. **写结论（含失败）**：无论 H1/H2 成立与否，写进 `references/TAIL_RISK_THESIS.md`
   的对应小节，并标注"第二外源集"。

## 4. 与红线的交互（容易踩的三处）

| 红线 | 在本任务中的具体含义 |
|---|---|
| 8（非预注册前瞻） | 若该源是**已发布**数据集，一律写 temporal holdout；只有"发布后新产生的数据"才可能算前瞻 |
| 9（三端点并列） | 第二外源集若只做 1 个端点，结论必须写"单端点，不外推" |
| 7（gate 判别力需 CI） | 新源上的 gate AUC 必须给 DeLong CI，点估计不得单独引用 |
