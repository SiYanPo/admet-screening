# 文献检索 SOP（相关性优先，防 IF 选择偏差）

**建立**：2026-11-19（100 篇文献精读的经验固化）
**适用范围**：本 skill 的所有 related work / prior art / 定位证据检索。

## 核心教训（为什么要写这份 SOP）

本轮实测：按**纯 JCR IF 排序**选"高分文献"时，TOP20 被 Cancer Cell / Nature 的
肿瘤基础模型占据——它们 IF 高但与 ADMET 证据准入毫无关系。若据此外推，会得到
"这个领域都是 foundation model，我的工作没意义"的错误结论。
**高分 ≠ 相关；IF 主导排序会引入系统性选择偏差。**

## 强制流程

1. **多主题检索**（≥5 个正交查询），不要单查询。
2. **本地相关性过滤**：`name + title + abstract` 必须命中领域核心词表，
   不相关的一律丢弃（不看 IF 多高）。
3. **排序公式**（`lit_search_100/merge.py` 可复用）：
   ```
   score = (核心词命中×6 + 主题重叠×4 + ln(1+IF)×3)
           × 主题权重 × 年份加权 × 期刊加权
   零核心词命中：score −= 100
   ```
   要点：IF 用**对数压缩**且只占一部分权重；相关性是主排序键。
4. **IF 口径固定**：JCR2025 年度值，**不是文章发表当年 IF**；
   未收录期刊标"未收录"并保留，不因查不到 IF 删除。
5. **逐篇精读摘要**：读真实摘要而非标题臆测；被截断处不推测。
6. **交叉去重**与来源分级：一手（出版社/arXiv/官方） > 二手索引 > 社区发现服务。
7. **证据分级入表**：每条结论标【一手已验】/【Agent 核实】/【预印本】/【未核实】。

## 代码化

- 语料构建脚本：`lit_search_100/merge.py`（PubMed 语料）、
  `skill_market_100/search_filtered.py`（市场语料，同样先过滤后排序）。
- 两者共享同一纪律：**先相关性过滤，后热度/IF 排序**。

## 与 G10 的关系

文献结论进入 `CLAIMS_REGISTRY.yaml` 时，须带 `expect_field_path` 或
`expect_code_symbol`（字段级证据），并标注来源 URL；不得只写"某顶刊说……"。
