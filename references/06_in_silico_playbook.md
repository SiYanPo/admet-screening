## 1. 建模方法

### 1.1 多证据整合框架【互证 + 新增】

- **三标尺等权百分位整合**：Vina 单构象 + 多构象共识对接 + DeepPurpose，各自转为百分位后等权合并 →
  综合梯队。与我们"排序不可用、只认三态"的裁决不冲突：该会话的候选是**文献天然产物 14 个**（同分异构简并），
  与我们同样的窄动态范围问题；其修正案见 §1.3。
- **暴露轴正交筛选【新增，本项目缺口 L2 的直接可抄方案】**：结合能力与口服暴露**强负相关**
  （实测 ρ = −0.76, p = 0.0015）——"驱动结合的极性恰抑制吸收"。任何只看结合的排名都会系统偏向
  吸收差的分子。落地方式见 §1.4 PBPK。
- **两轴正交合法性检验**：合并两个证据轴前先算轴间相关（结合 vs 暴露 ρ = −0.11 → 统计正交，合并合法）。
  若两轴高度相关，合并就是重复计数。这条应作为 skill 出"综合判断"前的强制检查。

### 1.2 LE 法证反推（抓"图画错但数据对"）【新增，强烈推荐】

对任何外来数据包（论文表格、他人对接结果），用配体效率反推重原子数做结构审计：

```
HA_recovered = |ΔG_bind| / LE        （LE 通常取 Table 中给的或 |ΔG|/HA 逆推）
```

实测战果：某图表包 Table 1 给出 J 的 LE 与 ΔG，反推 HA = 27.0 —— 只与**文献 J**（C18H24O9, HA=27）
吻合，与图上画的分子（HA=28）不符 → 证明"数据用对了分子、2D 图画错了"。成本为零，一次乘法。

### 1.3 排名的放行条件【互证】

- 差向异构体对接分差 0.26 kcal/mol ≈ 打分精度 → **"0.5 kcal/mol 以内差异不可过度解读"**。
  与我们"协议系统差 0.1–0.3"一致，可合并表述为：Vina 级别的分差 < 0.5 一律视同并列，用 MD/自由能决胜。
- 中段排名的波动来自 17 扭转键糖苷的采样随机性 → 用第二种子（seed 43/44）重复验证波动幅度
  ——我们只跑了 seed 42，这条值得补。

### 1.4 PBPK 暴露模型（bottom-up 筛查级）【新增，完整方案】

定位：**exposure-based triage**（相对排序 + 机制归因），不预测绝对浓度。实测配置：

- **结构**：10 状态灌注限制多室（胃肠腔→肠壁→门静脉→肝 well-stirred→体循环→肾/肌肉/脂肪/富血流），
  70 kg 生理参数锚定，LSODA 积分。
- **参数映射**（全部由 2D 描述符推导）：ka/Fa ← TPSA（Veber）；溶解度 ← ESOL；fu ← logP 映射
  （后被 ADMETlab 预测值替换，见 §3.2）；肝清除 E 做三档场景（0.05/0.2/0.5）。
- **强制校验（全部抓到过真 bug）**：
  1. 质量守恒误差 < 0.01%（抓到：门静脉血流重复计入体循环、肾清除只加尿未扣血浆——两处都被守恒检查暴露）；
  2. 场景稳健性：排序对 E 全区间（0.05→0.5）不变才算稳；
  3. 蒙特卡洛 UQ：2000 次抽样、折半收敛 < 0.05，输出"进前 3 的概率"而非点估计
     （抓到：`np.empty(2000)` 配 `range(500)` 的未初始化内存污染——发散到 1e296 的假数值）。
- **结果锚点（本化学类）**：TPSA 146–192 全超 Veber 140 → Fa 仅 0.31–0.52；Cmax 131–400 nM@100 mg；
  t1/2 5.9–10.5 h。
  > **口径更新（v2.6.0 整合）**：上述 t½ 5.9–10.5 h 来自外部会话的旧 E 场景 + fu≈0.99 假设。
  > 本 skill 的 `pbpk`（v2.4+，CLint 取 ADMET-AI、fu 取 ADMETlab 预测 22–43%）给出
  > **t½ 1.6–2.0 h**（Cmax 131–445 nM、F 8.8–23%）。两者差别**主要来自 CLint 输入不同**
  > （Vd≈65 L / CL≈30 L/h → 1.5 h），不是模型错。引用时按来源标注，勿混用。
- **边界声明模板**：位置异构体 2D 描述符简并（PBPK 只有类间分辨率）；绝对 AUC 受清除不确定性
  ~6.6 倍波动，只可用于排序不可用于剂量。

### 1.5 异构体 3D 分辨【新增】

2D 描述符简并的类内分辨：对每个异构体的构象系综算**分子内氢键数**（角度判据 D-H···A > 110°
与纯距离判据结果不同——判据敏感，两套都报）。实测：M 的分子内氢键最少（3.12 vs E 4.07）→
极性基团最外露 → **一条 3D 性质同时解释"DP1 结合最强"与"膜通透最弱"**。
注意范围限定：该机制解释只在同类内成立，跨类相关性弱（ρ=−0.33）不可外推。

### 1.6 代谢级联扩展【新增】

苷元两物种：切糖（−162.05）+ 级联切酯（肉桂酰 −146.04）→ 苷元/端酸两套描述符各跑一遍 PBPK。
MW 校验必须做（端产物：咖啡酰类→咖啡酸 180.04、阿魏酰类→阿魏酸 194.06，14/14 吻合即反证
结构解析正确）。SMARTS 切酯时注意羰基 O 是否在模式内（多删一个氧 = 差 16.0）。

## 2. 分子对接与分子动力学

### 2.1 对接协议（re-docking 资质验证）【新增，本项目未做、应补为 Gate】

1. **红ocking 验证是协议 Gate**：共晶配体（BW245C/A1AF8）对接回原口袋，**best RMSD ≤ 2 Å**
   才算协议合格。注意看**前几名的最小 RMSD**而非 top-1（17 扭转键柔性配体 top-1 RMSD 2.68 Å、
   mode 4 = 1.09 Å 属正常）。
2. **共晶配体成键必须对权威 CCD 核对**：obabel 距离感知成键后，与 PDB CCD 字典的分子式/连接性
   比对（实测 C19H32N2O5 精确吻合才算过）。
3. **受体制备的三个实测坑**：
   - `gemmi.remove_chain` 在迭代快照循环里**不可靠**（B/N 链删不掉）→ 改 PDB 文本过滤（确定性）；
   - gemmi 写 PDB 会把 5 字符残基名截断（A1AF8→A1A），按截断名抓配体；
   - obabel 的 pdbqt 输出带 COMPND 头 → **Vina 直接拒绝** → 过滤只留 ATOM 行。
4. 口袋定义：共晶配体质心 ± 11.25 Å（22.5³）；exhaustiveness 32（资质验证）/ 16（批量）+ 固定 seed。

### 2.2 多构象共识对接【互证】

50 构象/化合物 → 聚类取 10 代表 → 独立对接 → 取全局最优 + 打分均值双口径。
与我们 `m_dock_true.py`（ETKDGv3 400 池 + MMFF94s + Butina 1.2 Å + 10 代表）完全同思路，互证成立。
新信息：**14 化合物 × 10 构象 = 140 次对接在 CPU 上约 90 分钟**，可全量做，不必只做头部。

### 2.4 量子化学（xTB / PySCF / Multiwfn）【新增】

- **PySCF 免注册替代 ORCA**：conda-forge win-64 有（2.14）；水 B3LYP/def2-SVP = −76.35821 Eh
  （与文献一致）；**必须用密度拟合 DF-B3LYP**（普通 RI-JK 在 7.7 GB 机器上 CVHFallocate 崩，
  DF 内存降一个量级、能量差 0.1 kcal/mol）；conda 环境要在 PATH 加 `Library\bin` 否则 delay-load DLL 失败。
- **xTB 与 DFT 的轨道能系统性偏移**：xTB HOMO/LUMO ≈ −10.3/−8.1 eV，B3LYP ≈ −5.9/−2.0 eV——
  **论文只可引用 DFT 值**；但 Fukui/ESP 等相对描述符两法结论一致（方法级别稳健）。
- **Multiwfn 按扩展名识别格式**：`wfn.xtb` 不认，必须是 `.molden` 后缀（xtb 输出重命名）。
  批处理交互序列：函数 7→1（Hirshfeld）；函数 12→0（ESP 统计）→ `n` 退出。
- **xTB Windows 版**：不支持 `--cm5`，用 `--json` 解析 Mulliken；JSON 内含未转义反斜杠需清洗。
- **SDF 无氢大坑（最高优先级教训）**：SDF 库 13/14 化合物只有重原子，脚本不补氢 →
  xTB 在"无氢自由基片段"上算，gap 0.02–0.5 eV、MD 秒崩。**警报信号**：① 日志 `atoms = heavy`；
  ② gap < 1 eV；③ molden 氢计数。修复：`Chem.AddHs(mol, addCoords=True)`（幂等）；
  注意 AddHs 把 H 追加到尾部 → **重原子索引不变**，Fukui 站点归属按此对齐。

## 5. 与本项目的结构判定分歧：Regaloside M（记录在案）

两条独立工作线对 M 的连接性得出**相反结论**，方法论上值得写成案例：

| | 本项目（第八轮） | 外部会话 |
|---|---|---|
| 数据源 | 一手页（化合物 1，表 1 **含 HMBC 列**）+ HRMS | 时嘉琪学位论文化合物 11 的 ¹H/¹³C 位移表（无 HMBC） |
| 关键判据 | **HMBC 双向**：H-2(5.32)→CH₃CO(170.8) 且 H-Ac(2.08)→C-2(70.7) → **Ac@2**；H-3→C-9′ → 咖啡酰@3 | 化学位移类比：C-2 72.0"肉桂酰型酯甲川"→ **咖啡酰@2**；C-3 63.9 → 乙酰氧甲基 |
| 佐证 | 乙酰甲基 δH 2.08 = 仲醇乙酸酯（A/E/I 均 2.02 = 伯醇乙酸酯） | "2R 亚系一律 glc@1+酰基@2"拓扑归纳（从 I/H/L 反推） |
| 结论 | 真 M = 1-O-glc-**2-O-Ac**-3-O-咖啡酰 | "真 M" = 1-O-glc-**2-O-咖啡酰**-3-O-Ac |

**裁决（判据分级，写进 skill 的通用规则）**：

1. **HMBC 双向相关 > 化学位移类比推理**。类比的分辨力本身不足：乙酰化仲醇 CH（δC 70–74）
   与咖啡酰酯甲川（δC 72–74）区间重叠，单靠 13C **不可判**——两个会话其实独立写下了同一句话
   （本项目："这一项只能靠 HMBC 定，不能靠 13C 定"）。
2. "亚系拓扑规则"是**归纳而非演绎**——用 I/H/L 的拓扑外推 M，等于假设没有例外；对"新化合物"
   （原文声明）恰恰不能用。
3. 两份数据本身可能不同源（C-2 70.7 vs 72.0、C-3 62.5 vs 63.9）：**同名化合物的不同文献归属
   可能冲突，判定必须回溯到含 HMBC 的那一手**。
4. 操作规则：凡 NMR 判连接性，**必须先确认数据页含 HMBC 列**；只有位移表时，结论一律降级为
   "推定"并在结构文件里挂 `evidence: inference_only` 标记。

## 6. 建议纳入 skill 主流程的 Gate（按优先级）

1. **G-dock：红ocking 资质验证**（共晶配体 best RMSD ≤ 2 Å + CCD 核对）——任何对接批次的前置。
2. **G-H：输入分子氢原子计数检查**——QC/构象搜索前 molden/xyz 的 H 数必须 = 期望值。
3. **G-LE：外来数据包的 LE 反推审计**（一次乘法抓图错）。
4. **G-PBPK：质量守恒 + 场景稳健 + MC 收敛三校验**后才允许输出暴露排序。
5. **G-NMR：位移表无 HMBC → 结构结论只能标"推定"**。
6. **G-axis：合并任意两轴证据前先算轴间相关**（|ρ|<0.5 才算正交可合并）。

## 7. B3 MD 收敛门（已实现：examples/md_convergence_gate.py）

对任何用于 MM-GBSA / 占据率的轨迹，先过收敛门：

- **主指标：接触图 Tanimoto 驻留**——每帧"配体-受体接触残基集合"与相邻帧的 Jaccard。
  明确弃用配体 RMSD：它会把同一结合模式内的合理重定向误判为失稳。
- **配套：块平均误差**（Tanimoto 序列分 5 块，块间 SD / sqrt(5)）。
- **判据**：帧数 < 20 → `insufficient_frames`；末四分之一 mean ≥ 0.85 且块误差 ≤ 0.10
  → `converged`；否则 `not_converged`。
- **失效动作**：不收敛/帧不足时，所有 MM-GBSA 与占据率表述**自动封顶为"静态敏感性假设"**
  （与 A1 措辞封顶联动）。

实测演示：md/Mv2 生产 9 帧时运行 → `insufficient_frames`（正确拒绝）。
该脚本自带 DCD 读取器（头 276 B、unit-cell 记录在 x/y/z 之前，与 e7 实测格式一致），
只需 numpy，可在 md 环境直接跑。

## 8. B1 跨批锚点协议（已实现在 bt 适配器；w1/w2/w3 项目级脚本同法适用）

**同源不同批次的结果不可默认可比。** 规则：

1. 每次批量提交把 controls.csv 的 2 条阳性对照混入队列（不是事后补测）；
2. 对照实测值与 `expected_min/max` 区间比对，出界 → 该批标 `batch_drift`；
3. `batch_drift` 的批次与历史结果比较时，分差必须超过对照自身波动才有效，
   否则结论降级为"批内可比、跨批存疑"。

bt 适配器已实现：`control()` 自动比对并在日志打出 `BATCH_DRIFT`，
`batch_drift(option)` 返回漂移描述供上层写进 provenance。对 W1/W2/W3 项目级脚本，
按同一协议在提交列表头部加入对照 SMILES 即可。

## 9. MM-GBSA 证据等级协议（四级，v2.0）

结合自由能的结论强度必须与计算量匹配，**每一级允许的措辞不同**（与 A1 措辞封顶联动）：

| 级别 | 条件 | 允许的表述 | 本项目实测 |
|---|---|---|---|
| L1 单帧 | 一个构象/一帧 | "单点估计 x kcal/mol（无不确定度）——**静态敏感性假设**" | 真 M 单帧 −54.0（三自校验过） |
| L2 多帧 | 2–19 帧，均值±SE，**未过收敛门** | "n 帧静态敏感性估计 x ± e kcal/mol（帧数不足，未过收敛门）" | **n=9：−55.56 ± 0.86（SE），SD 2.59**（2026-10-27 23:12；dE_bond=0、平移对照 +0.00 均过；收敛门 insufficient → 封顶） |
| L3 正式 | ≥20 帧**且过收敛门**（接触图 Tanimoto 驻留） | "n 帧结合自由能 x ± SE kcal/mol" | 待 md/Mv2 ≥20 帧 |
| L4 论文级 | L3 + 足够采样 + −TΔS（扭转熵校正）+ 与 L1-L2 全程一致 | "结合自由能 x ± e kcal/mol（方法：…）" | 未达 |

硬规则：
1. **升级必经收敛门**——L2 → L3 的唯一通道是 `md_convergence_gate.py` 判 converged；
   帧数增加但门不过，只能在 L2 措辞下更新数字，不得换表述。
2. **三自校验（dE_bond=0、100 Å 平移对照≈0、接触持续性）任何一级都不可省**——
   它们证明的是"方法实现无误"，不是"这个数值可用"。
3. **−TΔS 在 L3 之前不得隐含**——不带熵校正的 ΔG_bind 系统性偏负 5–15 kcal/mol，
   绝对值只能做内插比较（同方法同体系的相对排序），不得跨文献比较。
4. 换配体（如 M 结构修正）= 全部等级作废重算；但旧等级的方法学教训保留（如旧 E7 的
   CM5/Gasteiger 电荷不自洽问题）。

## 筛查级口服暴露：well-stirred 的必做自校验

```
Eh = fu_b·CLint_b / (Qh + fu_b·CLint_b)      # ★ fu 乘在 CLint 上，不是乘在 Qh 上
CLint_b(mL/min/kg) = CLint_microsome(µL/min/mg) × MPPGL × LW / 1000
    MPPGL = 45 mg/g liver, LW = 25.7 g/kg, Qh = 20.7 mL/min/kg
F = Fa × Fg × Fh
```

**自校验（唯一能抓"参数挂错位置"的检查）**：`fu=1` 且 `CLint_b = Qh` → `Eh` 必须 = **0.500**。
实测踩过：首版把 fu 乘在 Qh 上，Eh 0.34→0.80、Fh 0.66→0.20 —— **结论方向完全不变，
量纲也完全一致**，不做算例校验就发现不了（C81）。

**上游输入必须先过物理边界**：负 CLint（ADMET-AI 在 APAP 上给 −4.3）会让 Eh<0、Fh>1。
用 `reliability.in_phys_range()` 与裁决层共用同一判定（C80）。

**偏差校准**：拿 3–5 个已知 F 的已上市药回放，报告 pred/lit 中位数。
本项目实测 **0.65（系统性低估 1.5 倍）**，主因是模型对低清除药的 CLint 偏高 → Eh 偏高 → Fh 偏低。
引用绝对值必须给出校正因子并声明 n 很小。
