# 11 条 QA gate

每条都有本项目的踩坑出处。**不满足就停，不要"先算着"。**

## G1 结构真实性
- InChIKey 三级判定：全串相同 = 同一分子；前 14 位同、立体层不同 = 立体异构；骨架不同 = 位置异构。
- 糖苷类必须额外核：糖接端位还是中间（13C：糖苷化 CH₂ 68–69 / 糖苷化 CH 76–80）、
  乙酰位置（1H：**2.08 = 仲醇乙酸酯，2.02 = 伯醇乙酸酯**）、苷元三类（香豆酰/咖啡酰/阿魏酰）、E/Z。
- 3D 文件要贴回 2D 重判手性，并做**镜像（x→−x）阳性对照**。
- **禁止循环论证**：不能用"按自己理解手写的参照结构"去核对自己的结构。
- 出处：14 个分子里 2 个错（L 实为 epi-王百合苷 A；M 是位置异构体）。

## G2 状态标准化不得破坏立体
互变异构体规范化默认会**丢掉双键立体**：真 M 经默认参数后 InChIKey 从
`MPZFXDIZHZVXBJ-SGKFEUNSSA-N` 变成 `...-DMLMUOLJSA-N`，`/C=C/` 变 `C=C`。
必须 `SetRemoveBondStereo(False)` + `SetRemoveSp3Stereo(False)`，并加保护：
骨架 InChIKey 前 14 位不变、手性中心数不减、指定双键数不减，否则回退。

## G3 结构变了必须重算的范围
- 纯描述符（MW / 分子式 / TPSA / HBD / HBA / cLogP / RotB）→ 可复用。
- 指纹/图模型（ADMETlab、ADMET-AI、DeepPurpose、vNN 适用域、ProTox 近邻）→ **必须重跑**。
- 3D 类（E3 溶剂化、E4 逐原子 BDE、E5 SASA）→ 必须重跑。
- 对接姿势、MM-GBSA → 作废。
- 出处：位置异构体实测 E1 一列未变，但 ADMETlab 95/120、ADMET-AI 41/49 在动。

## G4 端点饱和扫描（每次运行都做）
≥90% 同向 或 概率极差 <0.05 或 连续列相对极差 <0.05 → `saturated_in_set`。
**注意区分**：`saturated_in_set` = 不能排序但绝对阈值仍有效；`invalid` = 越物理边界，连阈值都不能用。
把两者混为一谈会把"14 个都该报红旗"这样的正确结论一起丢掉。

## G5 物理越界检测必须带量纲守卫
`hi > b` 这种比较对**不同单位族**会误判（ADMETlab 的 MDCK 是 1e-6 cm/s，
对 log Papp 的上界 −3 天然成立）。先看 |median| ≥ 0.5 才当作 log 量处理。

## G6 源覆盖率
覆盖率 <0.30 的源整体降为背景（vNN 在糖苷类上 0.17 vs 官方 0.73）。
口径要写清：0.17 是 15 端点含 MRTD（36/210）；14 个分类端点是 0.112。

## G7 0 产物 ≠ 无代谢
BioTransformer 对本化学类 0 产物（咖啡酸、真 M），但对乙酰氨基酚 6 个、苯酚 2 个、甲苯 3 个。
**任何 0 结果都必须先跑同 option 的阳性对照**；对照 >0 而待测 =0 → `out_of_domain`。
另：数量对也不等于结果可用——对香豆酸 2 个产物里出现"生成咖啡酸"这种化学上荒谬的反应。

## G8 跨源分歧 → 弃权，不取平均
同端点跨源极差/中位数 > 阈值（概率 0.5、连续 3 倍）→ 输出 `UNDETERMINED`。
出处：DILI 上四个源四种失效。

## G9 排名三条件
候选 ≥30 个 / 最大同类簇（同分异构或同骨架）<30% / 源间分歧 <阈值。
三者同时满足才允许输出排名，否则只出三态 + Pareto front。
出处：14 个里 12 个落在 5 组同分异构（86%），MPO 排序 Spearman 0.024→0.112。

## G10 安全裕度用未结合暴露
`Margin = IC50,u / Cmax,u`，`Cmax,u = Cmax,total × fu`。

**档位（v2.2 修正，依据 Redfern et al. 2003 的暂行安全边际）**：

| 档位 | 判读 | 适用范围 |
|---|---|---|
| <10 | 红旗（任何适应症都不足） | 全部 |
| 10–30 | 仅危及生命适应症可接受（肿瘤/AIDS/部分感染） | 受限 |
| 30–100 | 常规可接受 | 严重疾病（卒中/帕金森/癫痫/哮喘/关节炎） |
| ≥100 | 宽松安全 | 轻度适应症（鼻炎/湿疹）、CNS、有超量风险者 |

现行业界趋势更保守：目标 ≥100 倍，或 10 µM 下无可检出抑制。
**v2.1 的"Margin >10 即足够"仅在危及生命适应症下成立，已作废该表述。**
fu 只有单源时只给档位并标"低置信"。
出处：真 M 的 PPB 从 57.0% 变到 64.2%（只是换了个位置异构），fu 会跟着动 7 个点。

## G11 每个 UNDETERMINED 必须带下一步
输出里出现 `UNDETERMINED` 而不写"补哪个实验"，视为不合格输出。
映射表见 `06_wetlab_bridge`（本目录暂并入 04_decision_funnel 的第 5 节）。

## 12. 措辞封顶表（A1，借自外部对接 skill 治理层）

**门没过不是报错，而是措辞自动降级。** 面向报告/论文的每句话必须取自
`adt/phrasing.allowed_statement()` 给出的模板，禁止越过模板自由发挥：

| 证据状态 | 允许的最高表述（tier） |
|---|---|
| measured（实测） | "实测结果为 X——结论：Y" |
| ≥2 独立方法组一致（high） | "N 个独立方法组实测/预测一致，结论：Y" |
| ≥2 独立组预测一致（medium） | "N 个独立方法组预测一致指向 Y（中位 x）" |
| 单一方法组内一致（medium/单组） | "单一方法组内多源预测 Y（同组证据不叠加）" |
| 灰区/低区分度/低置信 | "低置信预测 Y，待实测确认" |
| UNDETERMINED | 只能引用 action；禁止出现任何方向词 |
| 排名守卫未过 | 只许"并列/Pareto 前沿成员"；禁止"第 N 名" |

**T0–T3 的语义封顶（同行评审 §4 分歧 3）**：T0/T1/T2/T3 是**内部证据分层
（internal evidence tier），不是任何监管机构的 determination**。任何输出不得将其
写成、暗示为或映射为 FDA/EMA/NMPA 等法域的审批等级/监管结论；`tier` 命令的产物
在对外材料中必须伴随该声明。违反者按"越级表述"处理，与"证明/无毒"同级禁止。

**绝对禁止的表述**（无论证据多好）：
- 由对接 ΔG 反推 Kd / 脑内占有率（经验打分不具备该换算的物理基础）
- 由预测值直接推断人体剂量 / 安全窗
- "证明 / 无毒 / 安全"等定论词（最高只允许"一致指向 / 未见风险信号"）
- 单方法组内多源时使用"多来源一致表明"（同组证据不叠加，见 independence_group）

**require_sources 的语义已收紧**："要求 2 源" = 2 个独立方法组（independence_group），
同组多源不叠加（两票半原则）。reliab 输出的 `n_indep_groups`/`indep_groups` 列即独立票数。
