# SAP 预注册与可审计性升维（SAP_PROTOCOL）

> 对应处方：**L3-1（SAP + OSF/Zenodo）/ L3-2（adapter 契约测试 + 记录重放）/ L3-3（证据 DAG）/ L3-4（第二实现者复现升 blocking）**。
> 状态：🟡 方法学框架（G4 预注册已存在；其余为 v4.3 路线图项）。

## 1. L3-1：SAP 预注册（G4 → 完整 SAP）
- 将现有 G4（freeze/verify(sha256)/supersede/diff）升级为**完整 SAP（统计分析计划）**：
  把所有**分析分支决策树**预注册（含阈值、端点分层、弃权规则、统计检验选择）。
- 对接 **OSF 公共注册** + **Zenodo 存档**（并行）：每次发布冻结一份 SAP + 数据快照到 Zenodo，
  注册号写入报告脚注（见 SKILL.md 引用格式）。
- 任何偏离 SAP 的分析分支必须走 supersede 留痕，理由公开。

## 2. L3-2：adapter 契约测试 + 记录重放
- 每个外部源 adapter：`契约测试`（输入/输出 schema 断言）+ **响应快照**（每次分析落盘原始响应）
  + **重放模式**（用快照重跑，避免源漂移导致结果不可复现）。
- **CI 定期探活**：失效即告警并**自动冻结该源**（其裁决退化为 `out_of_domain`，不进计票）。
- 外部源输出"随时间漂移"（守护项未明说但已知），记录-重放是复现性的硬保障（评审 §4-3）。

## 3. L3-3：证据 DAG（源 ← 训练数据 ← 底层测定）
- 用有向无环图显式建模"源依赖的底层测定数据"：源 → 训练集 → 底层实验测定。
- **共同训练集探测**并入 F2：若两源共享训练数据祖先（如均源自同一公开库），其"独立性"须降级，
  不能仅看预测 ρ（ρ 可能未捕获共同祖先）。这是 C1/C4 在证据链层面的纵深补强。

## 4. L3-4：第二实现者复现升 blocking
- G2（外部独立复现）从"外部执行项"升级为**验收门禁**：v4.3 发布必要条件是
  **一名组外实现者仅凭材料包复现 ≥3 个核心数字**（如 risk–coverage AUARC、去污染后 F6 Δ、前瞻 PASS 失败率）。
- 材料包须含：环境 digest + 数据快照 + 复现脚本 + 预期数字清单，使组外实现者零追问即可复现。

**验收**：SAP 注册号入报告；adapter 契约测试 + 重放进 CI；证据 DAG 图入附录；G2 升门禁。
