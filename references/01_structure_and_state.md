# 1. 结构 gate 与状态标准化

## 1.1 InChIKey 三级判定

| 关系 | 判定 | 处置 |
|---|---|---|
| 全串相同（27 位） | 同一分子（含立体） | 通过 |
| 前 14 位相同、立体层不同 | 立体异构 / 差向异构 | 必须用一手数据定构型 |
| 前 14 位不同 | 位置异构 / 连接方式不同 | **视为不同分子，全部重算** |

实例：真 M `MPZFXDIZHZVXBJ-SGKFEUNSSA-N` vs 旧 M `FSTPKXZAVUTJHW-SGKFEUNSSA-N`
—— 骨架不同、立体层相同，是位置异构体（立体层相同只说明甘油构型一致，**不能用来证明同一分子**）。

## 1.2 糖苷类必查的四件事

1. **糖接在端位还是中间碳**
   13C 判据：糖苷化 CH₂ δC **68–69**；糖苷化 CH δC **76–80**。
   实例：N 的 C-2 76.1 → 糖接中间；M 的 67.4 / 70.7 / 62.5 → 糖在端位。
2. **乙酰位置**
   1H 判据：乙酰甲基 **δH 2.08 = 仲醇乙酸酯（接中间碳）**；**2.02 = 伯醇乙酸酯（接端位）**。
   这是最省事的一条：A/E/I 全 2.02，M 是 2.08。
3. **苷元类别**：p-香豆酰（4-OH，芳环 AA′BB′ 两对双峰）/ 咖啡酰（3,4-二 OH，邻苯二酚）/
   阿魏酰（3-OMe + 4-OH）。三者在 13C 上可分辨（OMe 56 左右；邻二氧化的两个 C 都在 145–150）。
4. **双键几何**：全系列为 E。注意状态标准化时会丢立体，见 1.4。

## 1.3 3D 与手性

- 从 pdbqt 的 `REMARK SMILES IDX` 得到 SMILES→serial 映射，坐标贴回 2D 后用
  `AssignAtomChiralTagsFromStructure` 重判，与 2D 逐一比对。
- **必须做镜像（x→−x）阳性对照**：镜像后所有中心应全部翻转，否则判定器无效。
- **CIP 不能跨取代模式直接比**：同一物理手性在不同取代下会写成 R 或 S。
  跨分子比较要用固定优先序的几何行列式，或 InChI 立体层（同取代集内可比）。

## 1.4 状态标准化（Gate 0.5）

顺序：去盐取最大片段 → 电荷中和 → 官能团标准化 → 互变异构体规范化。

**必须加立体保护**（实测教训）：
RDKit `TautomerEnumerator` 默认会去掉双键立体，真 M 规范化后
`/C=C/` 变成 `C=C`，InChIKey 从 `...-SGKFEUNSSA-N` 变成 `...-DMLMUOLJSA-N`。
正确设置：

```python
t = rdMolStandardize.TautomerEnumerator()
t.SetRemoveBondStereo(False)
t.SetRemoveSp3Stereo(False)
t.SetReassignStereo(True)
```

并加保护：骨架 InChIKey 前 14 位不变、手性中心数不减、指定双键数不减；
任一不满足则回退到规范化前的结构，并在 `state_flag` 记为 `tautomer_REVERTED(原因)`。

**为什么必须有这一步**：真 M 与旧 M 只换连接方式，ADMETlab 的 pKa 就从 6.93 到 7.03、
logD 从 0.83 到 0.57。若不固定互变异构体与质子化状态，这个漂移会更大，而我们会把它当模型误差。

**输入端要记两列**：`input_smiles`（原样）与 `calc_smiles`（标准化后）。
后者才是送进所有预测源的 SMILES，也是所有下游 join 的 key。

## 1.5 常见陷阱

- PubChem 的名称记录可能不指定糖基立体（Regaloside A/B），逐字比对会误报；
  必须用 InChIKey + 一手文献双轨。
- 文献里"化合物 1 / 表 1 / 图 1"的编号必须逐位核（BH16 ≠ BH6），
  且编号 + 分子式 + 对照化合物名三者要同时对。
- 图里没有碳编号时，从左到右的绘制顺序**可能**与表格编号方向相反，不能按位置直接对应。

## 1.6 NMR 判连接性的证据分级（G-NMR gate）

两条独立工作线对同一个 Regaloside M 得出**相反结论**（一个判 Ac@2/咖啡酰@3，
另一个判咖啡酰@2/Ac@3），复盘得出的分级规则——任何连接性判定必须先声明用的是哪一级证据：

| 级别 | 证据 | 可信度 |
|---|---|---|
| 1 | **HMBC 双向相关**（H-2→CH₃CO 且 H-Ac→C-2 这样的互指） | 定论 |
| 2 | **乙酰甲基 δH 类型**：2.08 = 仲醇乙酸酯（中间碳）、2.02 = 伯醇乙酸酯（端位）——同系列内横向比对 | 强佐证 |
| 3 | **糖苷化 13C**：CH₂ 68–69 / CH 76–80 | 定糖位置可靠，**定酰基位置不可靠**（乙酰化仲醇 CH 70–74 与肉桂酰酯甲川 72–74 区间重叠） |
| 4 | "亚系拓扑规则"类比（如"2R 亚系一律 glc@1+酰基@2"） | **只是归纳**，对原文声明的新化合物不可用 |
| 5 | 单项化学位移归类（"C-2 72.0 是肉桂酰型酯"） | 不足以判，只能标"推定" |

操作规则：
- **只有位移表、无 HMBC 列的数据页，结构结论一律降级为推定**，在结构文件里挂
  `evidence: inference_only` 标记；
- 同名化合物的不同文献数据可能归属冲突（实例：M 的 C-2 一份记 70.7、另一份 72.0）——
  **判定必须回溯到含 HMBC 的那一手**；
- 外来数据包可用 **LE 反推审计**：`HA = |ΔG| / LE`，重原子数对不上画的图 = 图错数据对
  （真实战果：抓到某图表包把 J 画错而数据用对）。

案例细节见 `references/06_in_silico_playbook.md` 第 5 节。

## 1.7 G0 补充：分子式交叉核验（D2，借自外部 skill S0）

SMILES → `CalcMolFormula` 的结果必须与文献报告的分子式/HRMS 一致，不一致即 hard stop。
实测战果（外部线）：苯甲脒 SMILES 写成 `NC(N)`，分子式 C7H10N2 ≠ 文献 C7H8N2，直接抓出价键写错。

配套硬门已实现在 `adt/normalize.hard_gates()`（normalize 自动执行，问题写入
`compounds.csv` 的 `hard_gate_problems` 列，非空即禁止分发）：
- `odd_electron(n)`：电子总数为奇——氢计数必须计入（`[CH3]` 的 3 个 H 是 explicit-H
  计数而非原子节点，漏加会把自由基判成闭壳层）；
- `radical_spec(n)`：RDKit 显式 radical 标记（电子总数可为偶，如含 `GetNumRadicalElectrons` 的原子）；
- `valence_error`：SanitizeMol 不过。

注意避免误拦：`[NH2]c1ccccc1` 是普通苯胺（N 价 = 2H + 芳基键 = 3），不是自由基。
