# 0. 范围与 9 层框架

## 这个 skill 回答什么

虚拟筛选（docking / 药效团 / 相似性）得到一批命中物之后，**哪些值得买、值得测、值得往下做**。
核心不是"把预测跑全"，而是**判断每个预测能不能信，并给出可执行的下一步**。

## 9 层（缺口坐标系）

| 层 | 要回答的问题 | 常用手段 | 本项目当初的状态 |
|---|---|---|---|
| L0 结构真实性 | 我算的是我要的分子吗 | InChIKey 三级 / 一手 NMR / 3D 手性 | 唯一做扎实的一层 |
| L1 理化与化学稳定性 | 溶得下吗？在 pH/血浆里活多久 | logD、溶解度、pKa、强制降解 | 只有计算 logP/logS，**无化学稳定性** |
| L2 吸收与转运 | 穿得过去吗？会被外排吗 | Caco-2 / PAMPA / MDCK / 转运体 | 只有分类预测，无正交源 |
| L3 分布 | 血浆里多少游离 | PPB / fu / Kp | 单源 |
| L4 代谢与反应性 | 谁代谢、代谢成什么、产物有毒吗 | CYP/UGT、SOM、反应性、产物鉴定 | **最大缺口** |
| L5 排泄 | 肾排还是胆排 | CLr、胆汁清除 | 空白 |
| L6 安全 | 心/肝/遗传/致癌/内分泌 | hERG、DILI、Ames、核受体 | 只有分类概率，**且大量端点饱和** |
| L7 暴露与剂量 | 给多少能到有效浓度 | IVIVE → PBPK | 有脚本未打通 |
| L8 靶点结合 | 结合强不强、能待多久 | docking / MD / MM-GBSA / residence time | 三角互证已做 |

## 边界（明确不做的事）

- **不做 regulator-grade PBPK**（Simcyp/GastroPlus 级别）；只做量级估算。
- **不算 pKa 的真值**（本机没有可靠 pKa 源），只标记"离子化状态可能不一致"。
- **不评估晶型/吸湿/光稳定性**（只能实测）。
- **不做生殖毒性**（成本过高），只能靠文献/同骨架外推并标"未评估"。
- **不模拟商业许可的 API**（如 XenoSite 的程序化接口）。

## 一条贯穿全篇的经验

> 大极性糖苷 / 天然产物这一化学类，几乎所有公开 ADMET 模型都在域外。
> 判断"能不能信"比判断"值是多少"更重要——
> 本项目 14 个分子 × 9 个源，最后能进决策的端点数不到两成。
