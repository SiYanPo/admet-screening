## 0. 更正公告：那批分子不是 post-cutoff（v4.4 自查，标签级错误）

### 0.1 发生了什么

初版（v4.3 结转 + v4.4 首稿）把外源集描述为 "post-cutoff 外源留出（文献年 ≥ 2023，n=9443）"。
时间条件是这样交给 ChEMBL 的：`document__year__gte=2023`。

**该参数在 ChEMBL activity 端点实测不生效。** 三条独立证据：

| 证据 | 实测 |
|---|---|
| 服务端 total_count | `>=2015` / `>=2021` / `>=2022` / `>=2023` 四种取值返回**同一个** `total_count = 19130` |
| 落盘缓存的年份分布 | `document_year` 从 **1995** 到 **2025** 全都有 |
| ≥2023 的真实占比 | **9.6%**（1842 / 19130） |

即：n=9443 那批分子是 **ChEMBL_37 hERG IC50 全集去重（时间混合）**，不是时间留出。

### 0.2 为什么这属于"必须自曝"而不是"小瑕疵"

本包整套外源认识论（红线 8：外源数字必须同句标注"非预注册前瞻"）**建立在"这是后见数据"这个前提上**。
前提错了，标签就错了：把时间混合集叫做 post-cutoff，等于给一个**回溯性**结果贴上**前瞻性**标签——
这正是本包一直在批评别人的那种"用标签代替证据"。

### 0.3 修法（已落地）

1. `run_external_holdout.fetch_activities` 增加 `year_mode`：**一律在本地按 `document_year` 重新切分**，
   并把 `requested_min_year / applied_min_year / n_before / n_after / year_unknown /
   cache_document_year_min|max / server_side_filter_reliable` 全部落盘（`LAST_FETCH_META`）。
2. 顺手修掉一个更隐蔽的缺陷：`_get()` 原本**先 `import requests` 再查缓存**，
   导致"完全离线但有缓存"的场景（评审复现包、干净机）直接 `ModuleNotFoundError`——缓存形同虚设。已改为缓存优先。
3. 新增 `run_external_cuts_summary.py`，把三套切分并排成一张可引用的表
   → `out_ext/external/external_cuts_summary.json`。

### 0.4 三套集合

| 记号 | 时间条件 | n | 中位最大 Tanimoto | overall AUC | 同批 always-positive | 判定码 |
|---|---|---|---|---|---|---|
| **mixed** | 不过滤（复现旧数字用） | 9443 | 0.241 | **0.581** [0.569, 0.593] | 0.679 | `boundary_quantified_but_no_usable_region` |
| **y2021** | `document_year ≥ 2021` | 1941 | — | **0.584** | 0.632 | **`trend_not_robust`** |
| **y2023** | `document_year ≥ 2023` | 959 | — | **0.598** | 0.628 | **`trend_not_robust`** |

> 旧数字（0.581 / n=9443）**可以逐位复现**（`--year-mode none`），所以不是算错，是贴错标签。
> 但对外只能用 y2021 / y2023 两套，且必须说明"两个切点、同一数据源"。

## 1. 两条负结果原本是分开的（更新标签）

| 编号 | 结论 | 数字 | 产物 |
|---|---|---|---|
| N-A | gate 作为"能否预测对"的分类器，在 hERG 上近乎无判别力 | AUC **0.580**；域内外准确率同为 0.826（Fisher p=1.000） | `out_ext/tdc/gate_audit.json` |
| N-B | 【2026-11-04 **已撤回**】原称「外源时间混合集上没有可用排序能力」 | 原证据是 AUC 0.581 与 always-positive accuracy 0.679 的**跨量纲比较**，无效（C01） | `out_ext/external/external_cuts_summary_v2.json` |
| N-B′ | 【2026-11-04 **已撤回**】原称「真时间留出同样没有可用排序能力」 | 同上；且按正确口径 y2021 的 accuracy 0.634 **>** prevalence 0.632，方向相反 | 同上 |

**数字**仍可逐位复现（AUC 0.581 / 0.584 / 0.598；accuracy 0.674 / 0.634 / 0.620；
逐分子差配对 bootstrap CI 见 v2 产物），但**由这些数字支撑的推断已整体撤销**：

1. 旧比较 `auc < always_positive_accuracy` 跨量纲：AUC 的随机基线是 0.5，
   always-positive accuracy 是分类准确率且恒等于 prevalence；
2. 正确双轨口径下 `accuracy_below_majority_class` = **True / False / True**，
   并非「三切点一致」，且仅 mixed 的配对 CI 显著为负（[-0.0084,-0.0005]）；
3. 三切点是 y2023 ⊂ y2021 ⊂ mixed 的**嵌套子集**（同一 ChEMBL_37 快照、同一
   靶点 CHEMBL240），`all(...)` 不构成 R2 要求的「至少复制一次」，属**伪重复**；
4. 外审 B 领域级修正：hERG 端点 estimand 未绑定实验金标准（真值应为膜片钳 IC50
   的电压协议／温度／血清／尾峰电流，而非 probability 0.5 切点），AUC 略高于 0.5
   在安全端点上不产生决策价值。**不得**翻转成「域外仍有弱排序能力」；处置为
   `inference_revoked_pending_estimand`（撤销推断资格，待端点卡与 Q4 求证后重估）。

见 `references/RETRACTION_NOTE.md`、`references/ENDPOINT_ESTIMAND_CARDS.yaml`。

## 2. 合读之后的推论（评审 §E1 的核心，这一层不受 §0 影响）

N-A 的评测在 **TDC 官方随机切分的 test 集**上做——那批分子与训练集同源同分布，即**域内**。
在域内，随便一个模型都"到处能预测对"（基率 0.826），门没有可增加值，AUC≈0.5 是**构造必然**，
不是门的失败。**用域内数据评价门，方法上就是错的。**

N-B/N-B′ 那批外源分子到训练集的中位最大 Tanimoto 只有 **0.241 < AD 锚点 0.35**——
按本框架自己的门，它们**会被全部拒答**。也就是说这两组实验测的不是"模型在域外好不好用"，
而是"**如果违背门、强行预测，会发生什么**"。

【2026-11-04 **已撤回**】以下联合结论原句作废：

> ~~门的价值只能用"被拒答样本上的强制预测崩溃"来测量……三个切分都崩
> （0.581 / 0.584 / 0.598，全部低于同批平凡基线），所以"域外不该回答"
> 这件事有自然实验支持。~~

作废理由：该句的**唯一量化支点**是跨量纲比较（C01）。按正确双轨口径，
AUC 95%CI 下界 0.569 / 0.560 / 0.562 均 > 0.5；accuracy 与 prevalence 的
逐分子差配对 bootstrap CI 仅 mixed 显著为负（[-0.0084, -0.0005]），
y2021 为 [-0.0062, +0.0108]、y2023 为 [-0.0209, +0.0063] 均跨 0 且 y2021
点估计方向为正。三切点嵌套，不构成独立的「自然实验」。
**且不得翻转**：在端点 estimand 未定义前，AUC 与 accuracy 都不承载
「门该不该拒答」的决策含义。**本节目前没有可引用的合成句，状态为待重估。**

## 3. 定量检验（重写）：哪一层稳健，哪一层塌了

### 3.1 初版声称的（在 mixed 上）

| 检验 | 结果 |
|---|---|
| 分子级 Spearman(T, 预测正确) | +0.0953，p=1.8e-20 |
| 桶级 Spearman（Q1→Q5） | +0.90，p=0.037；AUC 0.538 → 0.534 → 0.553 → 0.592 → **0.630** |
| 分桶敏感性 | 无 CI 完全不重叠的下行 |
| 判定 | `boundary_quantified_but_no_usable_region` |

初版据此写了"门划出的边界**方向**正确"。**这条在真时间留出上不成立。**

### 3.2 真时间留出上发生了什么

| 切分 | 桶 AUC（Q1→Q5） | 桶级 ρ | 三重检验同向？ | 判定码 |
|---|---|---|---|---|
| mixed（n=9443） | 0.538 / 0.534 / 0.553 / 0.592 / 0.630 | +0.90 | 是 | `boundary_quantified_but_no_usable_region` |
| **y2021（n=1941）** | 0.549 / **0.494** / **0.478** / 0.554 / 0.639 | 非单调 | **否** | **`trend_not_robust`** |
| **y2023（n=959）** | 0.599 / **0.422** / 0.588 / 0.663 / 0.627 | 非单调 | **否** | **`trend_not_robust`** |

**读法**：mixed 上那条漂亮的单调上升，**是时间混合的产物**——早期文献的分子天然更接近
TDC 训练集；把它们与 2021–2025 的分子混在一起，"越老越准"就伪装成"越近越准"。
一旦按年份切干净，桶间差异落到噪声量级（y2023 的 Q2 甚至掉到 0.422）。

### 3.3 结论必须降级（这是本次更正的核心）

| 命题 | 更正前 | 更正后 |
|---|---|---|
| 域外模型有排序能力吗 | 弱（0.581） | **【2026-11-04 撤回】推断资格已撤销**：旧判据跨量纲；正确口径见 §1。状态 `inference_revoked_pending_estimand` |
| AUC 是否随 Tanimoto 单调上升 | 是（ρ=0.90） | **不稳健**（2/3 切分非单调）❌ 撤回（此项保留，与 C01 无关） |
| 门是否"精确"划出了能力边界 | 方向正确 | **无法证明** ❌ 撤回 |
| 门该不该在域外拒答 | 该 | **【2026-11-04 撤回】待重估**：原「域外处处不可用 → 该拒答」由 C01 推出，支点失效；不得翻转成「不该拒答」 |

**【2026-11-04 已撤回】原合成句**：

> ~~门在域外的正确性是**保守的正确**，不是**精确的正确**……域外**在任何距离上
> 都不可用**，所以"全拒"这个粗糙动作恰好是对的。~~

撤回说明：产物自带反证 `max_bucket_auc_below_065_all_cuts=false`（而本节写
「三个切分里没有一个能稳定过 0.65」），且「域外处处不可用」的前提是跨量纲比较。
按外审 B 的领域级修正，正确处置是**撤销推断资格**，不是把结论从「无排序能力」
翻转为「有弱排序能力」。当前本节无可引用合成句。

这个版本比初版弱，但它是**两个独立切点支持**的版本。按 §0 的标准，弱的真话胜过强的假话。

## 6. 认识论分层（E3）：基石实验的适用域被收窄了

外源结果宣布基模型在新骨架上不可用时，基石实验（4 策略 × 9 代价点 × 20 种子）
的前提就收窄了：**它优化的是"基模型可用时的弃权策略"**。这不否定基石（域内决策仍然真实），
但它要求论文叙事**显式分两层**：

| 层 | 适用对象 | 有效组件 | 本包证据 |
|---|---|---|---|
| **域内**（Tanimoto ≳ 0.35，同源同分布） | hit 优化、同系物比较 | 基石实验（策略 × 代价点）＋ 多源计票 | `out_keystone_v43/results.json` |
| **域外**（Tanimoto ≲ 0.3，新骨架） | 新化学空间外推 | **只有门**（拒答）＋ 湿实验处方；排序/计票**均无效** | `external_cuts_summary.json`（三切分） |

**合成句（可引用）**：
> "证据准入先于证据组合"这一命题在域内是**决策层**主张（何时弃权），
> 在域外退化为**准入层**主张（是否回答）。两层不是同一件事，
> 把它们混在一句"框架整体有效/无效"里，是两个方向都会犯的错。

## 7. 与"门阈 0.35 是先验锚点、用它验证它是循环的"这条质疑的关系（R2）

评审 R2 的质疑成立且必须回答：外源实验里"门阈 0.35 拒答了它们"与"验证 0.35 是对的"
若用同一批数据，是循环。

本包的回答分三步：

1. ✅ **不依赖 0.35 的部分**：§3 的分层以数据自身分位数（Q1–Q5）分组，不用 0.35。
   阈值审计（`THRESHOLD_REGISTRY.yaml`）把 0.35 标为 `frozen: false` ——
   数据里 0.35 附近**没有断点**，它只是工程工作点。
2. ❌ **【2026-11-04 撤回】R2 要求的"复制一次"并未成立**：≥2021 / ≥2023 是
   同一 ChEMBL_37 快照、同一靶点 CHEMBL240 的**嵌套子集**（y2023 ⊂ y2021 ⊂ mixed），
   且旧「结论同向（都远低于平凡基线）」由跨量纲比较推出（C01）。正确口径下
   `accuracy_below_majority_class` = True / False / True，并不同向。
   这一项**从 ✅ 改为 ❌**，与 §1、§2 的撤回一致。
   —— §3.2 的桶级趋势不稳健这一层仍然成立，与 C01 无关，保留。
3. ❌ **仍未解决**：**第二个数据源/端点**没做。两个年份切点共享同一 ChEMBL 快照、
   同一目标（CHEMBL240）、同一实验体系，它们的"独立"只是时间上的。
   因此在第二个端点（例如 DILI 或 hERG 的另一个 assay 体系）上复现之前，
   本文档的所有外源结论**只能算单源证据**。该项登记为开放，不冒充已闭环。
