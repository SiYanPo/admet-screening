# P3 路线图：从"可证伪方法学"到"领域基准设施"（2026-11-03）

> **前置条件（硬）**：P3 的任何一项都不得在 P2 完成前启动。
> P2 完成 = ①预注册锚定 ②前瞻盲测（或明确声明"不做并说明原因"）③外部第二实现者复现。
> **理由**：一个还没有外部复现的框架去开"社区基准服务器"，等于用自己的尺子量自己，
> 而社区会把它当作独立第三方——那是把自我证明包装成共识。

## P3.1 社区基准（准入层版 TDC leaderboard）

| 项 | 内容 |
|---|---|
| **做什么** | 一个可提交的评测服务：外部团队上传"源 × 端点"预测，服务端返回准入层的 cost-weighted utility、coverage、误放率/误杀率，并与已登记的基线对比 |
| **不做** | 不做"预测精度排行榜"（那是 TDC 的活）；不评 AUC 高低，只评"证据该不该用" |
| **准入规则** | 沿用 `SOURCE_REGISTRATION_POLICY.md` 的 Clopper–Pearson 95% CI 上界 ≤5% 门（**执行入口**：`python -m adt.cli source-admit --results <csv> --outdir <dir>`，2026-11-03 接线） |
| **可复现要求** | 每个提交必须带：快照 sha256、环境指纹、命令；服务端在隔离容器里重跑一次，一致才计入 |
| **反作弊** | 提交方必须声明与训练数据的关系（是否见过测试集）；声明为"未见"但被检出高 Tanimoto 邻居 → 标 `suspect_leakage`，结果单列不合并 |
| **启动条件** | 第二实现者复现报告**已公开**（解耦要求，见下） |

**与 P2.3 解耦（外部评审 R-C 要求）**：第二实现者复现必须先于基准上线公开，
否则"基准发布的可信度建立在自证上"。

## P3.2 负结果库（把负结果做成独立学术产出）

| 项 | 内容 |
|---|---|
| **现状** | `NEGATIVE_RESULT_DEFAULTS.yaml` 已有 8 条负结果落成默认值；`failure_modes.py` 有骨架；37 条案例散在 `07_case_lessons.md` |
| **做什么** | 结构化可查询库：每条 = {失效模式, 触发条件, 实测证据路径, 复现命令, 对用户的建议动作}；导出为静态站点（无后端，便于长期存活） |
| **FAIR** | 每条带唯一 ID、可引用 DOI（Zenodo 快照）、机器可读（YAML/JSON）+ 人可读（Markdown） |
| **价值** | 负结果的引用率天然低但**方法学价值高**；单独成文比塞进主文附录更可能被引用 |
| **验收** | `python -m adt.cli failure-modes --export yaml` 能吐出全部条目，且每条 evidence 路径存在 |

## P3.3 大模型交叉验证协议 —— **暂缓（附理由）**

外部评审 R-C 明确反对在现阶段把大模型当"外部验证"：

1. **循环论证风险**：本包批评多源"共享训练生态不算独立证据"；大模型同样在
   ChEMBL/PubChem 上训练过，其"独立意见"与源之间**不独立**。
2. **不可审计**：模型版本会静默变化（API 背后的权重更新），无法满足本包的
   manifest/快照纪律——今天能复现，三个月后不能。
3. **校准缺失**：大模型对"概率/阈值"的输出未校准，把它当第二评审人会引入新的
   不可量化误差。

**唯一可接受的形态**（若将来要做）：
- 先把大模型**作为一个"源"注册**（走 F1 门 + independence_group=`llm_prior`），
  声明其训练数据重叠风险；
- 只把它用于**定性分歧发现**（"它和框架结论不同的分子挑出来人工看"），
  不用于任何数字型结论；
- 全部对话与提示词落盘，进快照库。

在此之前，D1–D3 类疑点走**人类专家通道**（见 `references/PEER_REVIEW_2026-10-31.md` 的
求证流程），不走模型通道。

## P3 时间序（建议，不承诺日期）

```
P2 完成 ──┬──► P3.1 基准（3–4 个月，含服务开发与首轮外部提交）
          ├──► P3.2 负结果库（1–2 个月，主要是结构化整理）
          └──► P3.3 冻结（仅在完成"LLM 作为源"注册审查后解冻）
```

**纪律**：P3 的任何一项上线时，必须同时发布"本设施**不能**回答什么问题"。
一个不声明边界的基准设施，会迅速退化为"又一个排行榜"。
