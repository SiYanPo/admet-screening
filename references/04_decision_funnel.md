# 决策漏斗

## 1. 门控（不是打分）

```
Gate 0   结构真实性      不通过 → 整批终止（不是"打个折"）
Gate 0.5 状态标准化      产出 calc_smiles，后续所有源都用它
Gate 1   理化 + 稳定性   溶解度 <10 µg/mL 且 t½ <2 h（口服）→ FAIL
Gate 2   渗透与转运      Papp <1e-6 cm/s 且外排比 >3 → FAIL
Gate 3   代谢与反应性    Michael 受体 / 邻苯二酚 / 成醌 / TDI 提示 → 强制进 Batch-2 湿实验
Gate 4   安全            饱和端点不投票；越界端点不用
Gate 5   靶点结合        仅在"需要机制解释"时做 MD/MM-GBSA
Gate 6   暴露与裕度      Margin 三档，不给小数
```

每个 gate 的输出必须是三态：

| 状态 | 含义 | 必须附带 |
|---|---|---|
| `PASS` | 该 gate 的判据全部满足 | 依据（哪个源、哪个值） |
| `FAIL` | 明确不满足 | 具体阈值与实测/预测值 |
| `UNDETERMINED` | 数据不足或在域外 | **补哪个实验才能判** |

禁止输出"综合分 0.72，建议优先"这种没有三态的说法。

## 2. 什么时候才允许排名

三条同时满足：

1. 候选数 ≥ 30；
2. 最大同类簇（同分异构或同骨架）占比 < 30%；
3. 至少 2 个独立源的端点间分歧 < 阈值。

不满足 → 只输出 Pareto front（保留不被支配的解）+ 三态，不排名次。
Pareto 在动态范围窄时仍然有意义，因为它只淘汰被支配解，不做绝对位次。

综合分（若必须给）用**几何平均**而不是加权和：加权和会被长板补偿，
几何平均会被最差项主导——后者才对应"不能有致命短板"的决策语义。

## 3. 端点阈值（示例，按项目调）

| 端点 | PASS | 关注 | FAIL |
|---|---|---|---|
| 动力学溶解度 (pH 7.4) | >60 µg/mL | 10–60 | <10 |
| logD7.4（口服） | 0–3 | 3–4 或 −1–0 | >4 或 <−1 |
| Caco-2 Papp A→B | >5e-6 cm/s | 1–5e-6 | <1e-6 |
| 外排比 (B→A / A→B) | <2 | 2–3 | >3 |
| 肝微粒体 CLint | <30 µL/min/mg | 30–100 | >100 |
| PPB (fu) | fu >10% | 1–10% | <1% |
| hERG（预测） | <0.1 | 0.1–0.5 | >0.5 |
| DILI（预测） | 只用绝对阈值 | — | >0.5 且 ≥2 源一致 |
| Ames（预测） | <0.3 | 0.3–0.5 | >0.5 且 ≥2 源一致 |
| 化学稳定性 t½ | >8 h | 2–8 h | <2 h |

**这些阈值没有一条来自我们自己的实测**（本项目零实测），
它们是文献 + 审评惯例的起点。**第一批湿实验回来后必须用实测重标这些数字**，
并在文件里记下"阈值来源 = 实测/文献"。

## 4. desirability 形状

- 线性升：`d = clip((x - x_fail)/(x_pass - x_fail), 0, 1)`（如 fu、溶解度）
- 线性降：`d = 1 - 上式`（如 PPB、CLint）
- 阶跃：`d = 1 if x <= thresh else 0`（硬红旗：PAINS 机制类、Ames 阳性）
- 倒 U：logD 类，窗口外两侧线性衰减（`d = min((x-lo)/(mid-lo), (hi-x)/(hi-mid))`）
- 剂量校正：溶解度按预计剂量换算成剂量数 `Do = 剂量/溶解度`，再映射

## 附：湿实验 → 计算机替代 映射表（G-替代法定位，2026-10-28 补）

湿实验不可行时（无实体化合物/无合作实验室），每个端点的**计算机替代与它的可信度声明**。
替代值一律 `domain_flag=predicted`，永远不得写 measured 语义（措辞封顶自动执行）：

| 湿实验 | 计算机替代 | 替代可信度声明 | 何时仍必须实测 |
|---|---|---|---|
| PAMPA / Caco-2 渗透性 | ADMETlab 3.0 Caco-2 / HIA（W1）| "预测一致指向"级；本化学类全组 −6.5~−5.8（域外趋势可信，绝对值不可信） | 仲裁中段候选排序；校准 ka |
| 肝微粒体稳定性 | **ADMETlab 无此端点（缺口）**；替代 = E4 xTB 软点 + chembl CLint 邻居分位（参照级） | 只能给"相对快/慢"，无数值结论 | 任何清除相关的定量结论 |
| 血浆蛋白结合 | ADMETlab fu（W1）| 单源 → Margin 只给三档且标低置信 | fu<10% 分子的安全裕度计算 |
| hERG | vNN + ADMET-AI + ADMETlab 三源共识 | 跨 2 独立组一致才敢说"未见风险信号" | 任何"心脏安全"表述 |
| DILI / Ames | 四源共识（分歧时弃权） | 本化学类全饱和 → 基本必 UNDETERMINED | **这是实测的第一优先级** |
| 化学稳定性（pH/血浆 t½） | **完全空白**（L1 缺口） | 无 | 糖苷/酯键类的第一关 |

用法：reliab 输出 UNDETERMINED 且 action 指向"补实测"时，按本表找该端点的替代源补一层
预测；**替代之后仍是 predicted**——只有表中最右列的实测能把结论升为 measured/high。
