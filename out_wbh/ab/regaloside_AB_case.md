# Regaloside A vs B：17.5× 口服生物利用度差异的 case study（方向B）

> ⚠️ 2026-11-07 更正：F 比值 = 9.1/0.52 = 17.5×（原稿误写 9×）。外部核实（DOI 10.1556/1326.2026.01506）明确：口服后 A 的 AUC/Cmax **高于** B，A 的低 F 来自其极低清除率抬高的 IV 参照，不是吸收差。本 case 不得再用于论证『框架把差异定位到转运体/代谢层』。

## Regaloside_A — 1-O-β-D-吡喃葡萄糖基-3-O-对香豆酰甘油
- CAS 114420-66-5；C18H24O10；MW 400.38；口服 F = 0.52%
- 结构式来源：AbMole M19006 / InvivoChem (CAS 114420-66-5)
- 糖苷轴：键型=alkyl_glycoside，位阻位置=primary，酯键数=1，乙酰化=False，水解风险=high，苷元首过风险=high
- 被动轴：TPSA=166.1，MW=400.4，HBD=6，HBA=10，XlogP=-1.87 → unlikely；passive_closed → transporter_resolution_required

## Regaloside_B — (2S)-1-O-对香豆酰-2-O-β-D-吡喃葡萄糖基-3-O-乙酰甘油
- CAS 114420-67-6；C20H26O11；MW 442.41；口服 F = 9.10%
- 结构式来源：TargetMol/陶术 T4S0622 (CAS 114420-67-6)
- 糖苷轴：键型=alkyl_glycoside，位阻位置=secondary，酯键数=2，乙酰化=True，水解风险=high，苷元首过风险=high
- 被动轴：TPSA=172.2，MW=442.4，HBD=5，HBA=11，XlogP=-1.3 → unlikely；passive_closed → transporter_resolution_required

## 判定

框架无法在被动层区分 A 和 B（两者都 unlikely）。**但这不等于差异在转运体/代谢层。**外部核实（2026-11-07）指出：口服后 A 的 AUC/Cmax 反而高于 B（且 A 的口服剂量只有 B 的一半），A 的 F 只有 0.52% 是因为它的全身清除率极低、把 IV 参照抬高，不是吸收差；B 则是清除率显著更高、Vz 更大，血药浓度极低。因此本 case 只能声明一件事：**框架在被动层给出的『两者都不可区分』与实测不矛盾**。任何『框架把差异正确定位到转运体/代谢层』的表述都超出证据，不得对外引用。 诚实限制：当前的肠道水解**分级**对 A/B 相同，说明纯分级规则不足以区分两者；须用 bond_position/acetylation 这类细粒度描述符，或用 H1/H2 的实测来分辨。另注：F 是**剂量归一化**量（IV 与 PO 剂量在两组间都不同），F 比值 17.5× 不可直接解读为『B 的暴露高 17.5 倍』——实测恰恰相反。

### 框架能区分

- 糖苷键位阻位置：A=primary / B=secondary（新增 bond_position 维度）
- 乙酰化修饰：A=False / B=True（影响亲脂性与自由羟基）
- 酯键数量：A=1 / B=2
- 计算亲脂性：XlogP A=-1.87 → B=-1.30（Δ0.57）

### 框架不能区分（诚实限制）

- 肠道水解风险分级相同（都是 high）——现有规则不足以直接判 A/B 差异，这正是评审预判的'有价值的限制'
- 被动渗透预筛相同（都是 unlikely）——框架无法在被动层区分 A/B，必须把差异定位到转运体/代谢层

### 可检验假设（不是结论）

| ID | 层 | 假设 | 验证 |
|---|---|---|---|
| H1 | 水解 | B 的糖苷键在甘油 C2（仲碳，位阻大），模拟肠液水解半衰期应长于 A（伯碳） | SIF/SCF 孵育 0–24 h，LC-MS/MS 定量原型糖苷剩余率 → t½(B) / t½(A) |
| H2 | 被动渗透 | B 多一个乙酰基、少一个自由羟基（LogP 更高、HBD 更低），Caco-2 Papp(A→B) 应更高 | Caco-2 Papp A>B 双向 + 外排比 ER |
| H3 | 外排 | 若两者被动层都被 TPSA 关闭，则 A/B 差异必须由外排（P-gp/BCRP）或首过承载 | ± verapamil/ko143 的 ER 变化；门静脉 vs 外周血苷元/原型比 |
| H4 | 首过 | A 的游离 C2-OH 使其更易被肠黏膜 II 相酶/糖苷酶处理，首过更高 | 肠微粒体 + 肝微粒体共孵育，比较原型与苷元清除 |
